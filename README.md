# assets

Public image hosting for client email signatures and other HTML email work.
Email clients load these files through the jsDelivr CDN:

```
https://cdn.jsdelivr.net/gh/brandlabsae/assets@main/<path to file>
```

Everything in this repository is public. Only add files that are meant to be
seen by email recipients.

| Folder | Used by |
| --- | --- |
| [`fi-dubai/email-signature/`](fi-dubai/email-signature/) | Fi Dubai HTML email signature |
