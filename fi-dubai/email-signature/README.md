# Fi Dubai email signature images

Public image files for the Fi Dubai HTML email signature. Email clients load
them through the jsDelivr CDN, for example:

```
https://cdn.jsdelivr.net/gh/brandlabsae/assets@main/fi-dubai/email-signature/fi-dubai-logo@2x.png
```

| File | Pixels | Shown at |
| --- | --- | --- |
| `fi-dubai-logo@2x.png` | 340x112 | 170x56 |
| `banner-gulfood-manufacturing-2026@2x.png` | 1200x300 | 600x150 |
| `banner-fi-europe-2026@2x.png` | 1200x300 | 600x150 |
| `icons/facebook@2x.png`, `linkedin@2x.png`, `x@2x.png`, `instagram@2x.png` | 48x48 | 24x24 |

Do not edit these files here. They are generated by `assets/build/render.sh`
in the signature source (`fi-dubai/email-signature/` in the private
`zubair-content` repo) and copied over.

## Updating an image

1. Re-render it in the signature source, copy it here under the same name and push.
2. Clear the CDN copy so mail clients pick it up, for example:
   `https://purge.jsdelivr.net/gh/brandlabsae/assets@main/fi-dubai/email-signature/banner-fi-europe-2026@2x.png`

Signatures load the image by URL every time an email is opened, so the update
shows in sent emails too, without reinstalling any signature.
